# app-tarefas-lideres
O objetivo é organizar as tarefas de cada líder de campo para poder fazer uma gestão mais organizada de demandas e execução.

## Onde está o app
- **App em uso (link dos líderes e do atalho no celular):** https://claude.ai/artifact/Kz8PmEBg6fsbmEhyy2e6FM
- Os dados ao vivo ficam no banco interno desse app, no Claude. Este repositório guarda **cópias**: o código e fotos dos dados.

## O que tem aqui
| Pasta / arquivo | O que é |
|---|---|
| `app/index.html` | Código do app (versão publicada no link; v22 em 26/11/2026: aba Concluídas) |
| `backups/AAAA-MM-DD/tarefas.csv` | Planilha com todas as tarefas naquela data |
| `backups/AAAA-MM-DD/dados-completos.json` | Cópia completa do banco (líderes e tarefas, com IDs), serve para restaurar |
| `docs/projeto-gestao-tarefas-lideres.md` | Documento do projeto: o que o app faz, líderes, pendências e próximos passos |
| `docs/requisitos.md` | Requisitos da versão inicial (v0.1) |

## Como fazer mudanças
Peça no projeto "PROJETOS" do Claude. O Claude altera o código, republica no **mesmo link** (sem perder dados) e salva a nova versão aqui.
